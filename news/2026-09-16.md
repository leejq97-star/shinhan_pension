## ⚠️ 작업 참고사항

- **이메일 전송 실패**: Gmail MCP 커넥터가 계정에는 연결되어 있으나(`connected: true`) 이 채팅 세션에는 비활성화(`enabledInChat: false`) 상태여서 이메일을 발송하지 못했습니다. GitHub 백업만 완료했습니다. claude.ai 커넥터 설정에서 이 세션/스케줄에 Gmail을 활성화하면 다음 실행부터 정상 발송됩니다. **9/9일부터 9일 연속 동일한 사유로 이메일 발송이 실패하고 있습니다.**
- **뉴스 수집 한계**: (1) news.google.com, hankyung.com, edaily.co.kr 등 뉴스 도메인에 대한 WebFetch 직접 접속이 네트워크 정책상 차단되어 있고, (2) WebSearch 도구가 "최근 24시간"과 같은 엄밀한 날짜 필터를 지원하지 않아, 검색 스니펫과 URL에 포함된 날짜 패턴에 의존해 기사를 선별했습니다. 그 결과 신한은행·신한지주 키워드는 신규 기사를 확보하지 못했고, 다른 키워드도 목표치인 5건에 못 미쳤습니다. 매일 동일한 문제가 반복되고 있어 근본적인 개선(뉴스 API 연동 또는 허용 도메인 화이트리스트 확장)이 필요해 보입니다.
